# User-visible "Zed" strings that stay, each with the reason it is allowed to.
#
# script/check-branding.sh fails on anything here that is not listed, and on
# anything listed that no longer exists. An upstream merge that adds a new
# user-visible Zed string therefore lands as a failing job rather than as a
# silent regression: fix the string, or add it below with a reason someone else
# can check.
#
# Format: <path>|<the string, exactly as the scan prints it>
#
# The reasons fall into a handful of kinds:
#   unreachable   — the code compiles, but nothing in a running KnightCode can
#                   get to it. The argument is given, not asserted.
#   off-limits    — the crate is one the fork does not touch (editor, project,
#                   workspace, terminal, git, vim, gpui). Hidden, not edited.
#   identifier    — a font family, a theme name, a settings value or a path: it
#                   is configuration rather than a surface, and renaming it
#                   breaks existing settings files for no visible gain.
#   third party   — it names Zed Industries or their product, accurately, which
#                   is the point.
#   test          — test or preview code the scan's filters did not catch.
